# @dotasn/runtime

The support library of TypeScript generated by [DotAsn](https://github.com/Addemin94/DotAsn)
(`asn1 generate-typescript`). It holds:

* the descriptor and value types the generated code uses;
* the conversion between those values and the DotAsn JSON value notation;
* helpers for hexadecimal text and BIT STRING values.

It has no dependencies and runs in browsers and Node.js.

Encoding and decoding is done by [`@dotasn/wasm`](../wasm/README.md), the DotAsn .NET runtime compiled to WebAssembly,
which uses this package for typed values.

## Generated code

```sh
asn1 generate-typescript samples/telemetry --output src/generated
```

Each ASN.1 module becomes one TypeScript module. Each type becomes a TypeScript type and a descriptor constant with
the same name. `dotasn-schema.ts` holds the schema that `@dotasn/wasm` loads. Options:

| Option | Meaning |
|---|---|
| `--runtime-module <specifier>` | Import path of this package (default `@dotasn/runtime`) |
| `--import-extension .js\|.ts\|none` | Extension of imports between generated modules (default `.js`, for `"moduleResolution": "nodenext"`; `none` for bundlers) |
| `--modules A,B` | Generate only these modules |
| `--no-docs` | Leave out documentation comments |

## Value model

| ASN.1 | TypeScript |
|---|---|
| BOOLEAN, NULL | `boolean`, `null` |
| INTEGER | `number` when every permitted value lies within ±(2^53 − 1), otherwise `bigint` |
| ENUMERATED | a union of the identifiers as string literals, plus `UnknownEnumItem` when extensible |
| REAL | `number` (including `Infinity`, `NaN` and `-0`) |
| BIT STRING | `{ bytes: Uint8Array, length: number }` (first bit is the most significant bit of `bytes[0]`) |
| OCTET STRING | `Uint8Array` |
| OBJECT IDENTIFIER, RELATIVE-OID | dotted string, e.g. `'1.2.840.113549'` |
| Character strings and time types | `string` |
| SEQUENCE, SET | an interface; OPTIONAL and DEFAULT components are optional properties |
| SEQUENCE OF, SET OF | an array |
| CHOICE | an object with exactly one property, e.g. `{ heartbeat: {...} }`, plus `UnknownAlternative` when extensible |
| Open types | `{ type, value }` to encode; decoded as `{ encoded, rule }` |

## Value notation

```ts
import { formatNotation, parseNotation } from '@dotasn/runtime';

formatNotation(Heartbeat, { sequenceNumber: 7, uptimeSeconds: 4_000_000_000 });   // '{"sequenceNumber":7,...}'
parseNotation(Heartbeat, text);
```

`toNotation` and `fromNotation` convert to and from parsed JSON. Invalid values throw `Asn1NotationError` with the
`path` of the problem. The notation is described in
[docs/value-notation-json.md](https://github.com/Addemin94/DotAsn/blob/main/docs/value-notation-json.md).
